ZAPRET-DISCORD-YOUTUBE — РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
==================================================

Для Windows 10/11. Для управления службой, сетевыми настройками и hosts нужны права администратора. Запускайте проект только из доверенного источника:
https://github.com/Flowseal/zapret-discord-youtube/releases

ВАЖНО
- Это не VPN: программа меняет обработку сетевых пакетов на этом компьютере.
- Универсально рабочей стратегии нет. Результат зависит от сети, провайдера, региона и времени.
- Проверка Auto-Select оценивает ответы веб-адресов и, по выбранному режиму, передачу данных. Она не проверяет вход в аккаунт, звонки, чаты или работу каждого приложения.
- При замедлении канала самим провайдером («throttling») обход блокировки может не вернуть скорость.
- Профили МТС, МегаФон, Tele2/T2 и Йота экспериментальные; они не подтверждены реальными испытаниями у операторов и не гарантируют работу.


1. УСТАНОВКА И ПЕРВЫЙ ЗАПУСК
----------------------------
1. Скачайте ZIP со страницы релизов выше и `SHA256SUMS.txt` рядом с ним. До распаковки сверьте SHA-256 из манифеста.
   Windows PowerShell (из папки с ZIP и манифестом):
   $line = Get-Content .\SHA256SUMS.txt | Select-Object -First 1
   $expected, $name = $line -split '  ', 2
   $actual = (Get-FileHash -LiteralPath $name -Algorithm SHA256).Hash
   if ($actual -ne $expected) { throw 'SHA-256 mismatch' } else { 'SHA-256 OK' }
   Linux: `sha256sum --check SHA256SUMS.txt`; macOS: `shasum -a 256 -c SHA256SUMS.txt`.
   При несовпадении хэша или ошибке проверки не распаковывайте архив. Если в свойствах архива есть кнопка/флажок «Разблокировать», используйте её до распаковки (или распакуйте архиватором, который снимает блокировку).
2. Распакуйте архив, например, в C:\zapret. Не используйте OneDrive, кириллицу, пробелы и спецсимволы в пути.
3. Запустите zapret.bat. Подтвердите запрос Windows на запуск от имени администратора.
   Альтернатива — отдельная графическая панель `Zapret-Control.exe` (настоящее приложение с иконкой; запасной запуск — `Zapret-Control.bat`): те же действия (статус, запуск/остановка службы, автонастройка, рекомендации сайтов) без консольного меню. Панель не заменяет zapret.bat; классическое меню остаётся доступно из панели и двойным кликом по zapret.bat. Подробнее — раздел 2.
4. При первом запуске меню может предложить выбрать язык и запустить Auto-Select.
5. Чтобы подобрать стратегию вручную из меню, выберите пункт 13. Проверка может занять несколько минут. Во время перебора текущий обход может временно останавливаться.
6. Установка кандидата предлагается только после успешной повторной проверки и открытия install gate. Если проверка нестабильна или кандидат не даёт достаточного основания для замены, программа его не устанавливает; уже работающая служба остаётся прежней. Если вопрос об установке появился, пустой ответ означает «да». После установки будет отдельный вопрос об обновлении управляемого блока hosts и списка IPSet; пустой ответ также означает «да». От этих действий можно отказаться и выполнить их позже из меню.
7. После настройки проверьте нужные сайты и приложения сами. Успешный ответ веб-сервера не означает, что вход, аудио/видео-звонки или все функции приложения проверены.


Мастер меню 25 («Автонастройка: обычный или мобильный интернет») сначала спрашивает тип подключения; при мобильном варианте он спрашивает оператора и запускает соответствующий узкий профиль. При `-Carrier` эти два вопроса пропускаются и используется указанный оператор. Если повторная проверка и install gate подтверждают пригодный вариант, мастер отдельно спросит, устанавливать ли его как службу; только явное «да» применит эту настройку, пустой ответ означает «нет». После установки отдельный вопрос предложит обновить управляемый блок hosts и IPSet; пустой ответ также означает «нет». Флаг `-Install` означает явное согласие на установку и настройку hosts/IPSet, убирает вопросы о применении, но не отменяет повторную проверку и install gate. Без `-Install` флаг `-NoInteractive` запускает проверку без вопросов и без установки; если `-Carrier` не указан, используется обычный набор стратегий. Отчёт сохраняется, а профиль оператора при `-Carrier` может быть записан в `config.json` только после повторной проверки. DNS/DoH и системные сетевые параметры мастер автоматически не меняет. Еженедельная перепроверка предлагается отдельно и включается только после согласия или явного `-EnableSchedule`; по умолчанию она выключена.

Если выбранная стратегия не помогла, не считайте её гарантированно рабочей: запустите диагностику (пункт 11), проверьте DNS и попробуйте другой вариант.

Обновление существующей установки в той же папке:
1. Скачайте ZIP нового релиза и `SHA256SUMS.txt` с официальной страницы. Положите их рядом и сначала сверьте хэш способом выше.
2. Распакуйте ZIP в отдельную временную папку — не поверх установленной копии.
3. Запустите `Update-Zapret.bat` из распакованной папки. В окнах выберите скачанный ZIP и существующую папку установки, затем подтвердите обновление. Службы и процессы будут временно остановлены; установка остаётся на прежнем пути.
4. Обновлятор проверяет состав ZIP и версию, сверяет SHA-256 при наличии манифеста рядом с архивом, заранее проверяет доступность файлов и возможность заменить `WinDivert64.sys`, затем меняет файлы транзакционно. Если драйвер занят, замена не начинается: закройте другие программы/обходы, использующие WinDivert, и повторите. Не закрывайте окно до сообщения о результате.
5. `config.json`, `strategies-user.json`, журналы, списки `*-user.txt`, уже существующие `ipset-all.txt`, выбранные `ACTIVE_*.bin` и файлы `utils/check_updates.enabled` и `utils/game_filter.enabled` сохраняются. Если транзакция замены завершается ошибкой, обновлятор пытается вернуть прежние файлы. При неполном откате службы не запускаются, а резервные файлы остаются в скрытой папке `.zapret-update-*`. Если файлы обновлены, но прежний обход не удалось запустить, программа возвращает ненулевой код, сохраняет резервную папку и показывает предупреждение. Не запускайте службы вручную при сообщении о неполном откате; сохраните указанный путь и обратитесь за помощью.
6. После обновления проверьте нужные сайты: проверки оценивают доступность веб-endpoint'ов, а не работу приложений целиком. Начиная с версии 2.1.27 Telegram не проверяется и не поддерживается.
7. АВТООБНОВЛЕНИЯ (с версии 2.9.0; источник настроен с версии 2.9.2). Источник обновлений — файл `update-manifest.json` в репозитории проекта на GitHub (Orlovsky1504/NewZapret-beta-); поле `updateFeed` в `config.json` можно перенаправить на свой адрес (формат: `update-manifest.example.json`). Манифест описывает версию, ссылку на ZIP, SHA-256 архива и заметки к выпуску. Публикация новой версии: положите в корень репозитория два файла — ZIP релиза (ровно тот, что в папке релиза) и сгенерированный `update-manifest.json`; сборка релиза готовит манифест автоматически. Дальше: кнопка «Проверить обновления» в панели скачивает манифест, сверяет версию и при желании устанавливает обновление (скачивание ZIP, проверка SHA-256, та же безопасная замена файлов, что и в Update-Zapret.bat; настройки и списки сохраняются). Кнопка «Автоустановка обновлений» включает установку без вопросов — только после проверки манифеста и контрольной суммы; при сбое причина показывается в окне, а ручная установка остаётся доступной. В консоли то же самое: `zapret.ps1 check-updates` и `zapret.ps1 update-install`. Пока `updateFeed` не задан, кнопка честно сообщает, что источник не настроен; проверка апстрима Flowseal — это другой проект и на вашу сборку не устанавливается.


2. ГРАФИЧЕСКАЯ ПАНЕЛЬ ZAPRET-CONTROL
------------------------------------
`Zapret-Control.exe` — отдельная графическая панель с упрощённым управлением (приложение с иконкой; `Zapret-Control.bat` — запасной вариант запуска). Она работает с той же установкой, что и zapret.bat, и не заменяет его: классическое консольное меню остаётся доступным двойным кликом по zapret.bat и кнопкой из панели. Запустите панель двойным кликом по Zapret-Control.exe и подтвердите запрос прав администратора — они нужны для управления службой.

При первом запуске панель предложит создать ярлык «Zapret Control» на рабочем столе — с иконкой и без консольного окна. Дальше запускайте приложение этим ярлыком. Ярлык можно создать заново кнопкой в разделе «Дополнительно»; `Zapret-Control.ico` рядом с программой даёт иконку ярлыку и окну.

Панель состоит из пяти разделов; весь основной функционал консольного меню доступен прямо в окне приложения, а действия выполняются с живым журналом:

- «Обзор» — крупные карточки состояния: служба («Работает», «Остановлена», «Не настроена» или «Ручной запуск»), текущий профиль и состояние IP-фильтра. Статус обновляется автоматически; кнопка «Обновить статус» обновляет его сразу. Кнопки «Запустить службу» и «Остановить» управляют установленной службой; остановка временная и требует подтверждения. Кнопка «Автонастройка» открывает мастер прямо в панели: выбор обычного или мобильного интернета и оператора, проверка стратегий с показом хода выполнения, затем отдельные явные согласия — установка службы, обновление hosts/IPSet, еженедельная перепроверка. Повторная проверка и install gate работают как в пункте 25 меню; без явного нажатия ничего не устанавливается. Консольный мастер остаётся в классическом меню (пункт 25). На странице «Обзор» есть и карточка «Автозащита»: кнопка «Проверить обход» мгновенно проверяет все эндпоинты Discord/YouTube/WhatsApp через текущий обход и показывает результат в окне приложения; кнопка «Включить автозащиту» ставит фоновую проверку каждые 4 часа от имени SYSTEM — после двух подряд сбоёв запускается автоподбор, а служба переключается только на полностью подтверждённую стратегию (намеренно остановленная служба не трогается). Кнопка «Запустить трей» показывает значок у часов с быстрыми действиями: «Проверить обход», «Автоподбор стратегий» и «Открыть панель».

- «Мои сайты» — готовые списки доменов (YouTube, Discord, WhatsApp и другие). Выберите сервис и просмотрите домены, затем нажмите «Добавить выбранный сервис». Список показывается ещё раз, и личные списки меняются только после явного подтверждения — до подтверждения ничего не записывается. Домены, уже находящиеся в списке исключений, не добавляются: панель показывает пояснение и не меняет списки. После добавления панель отдельно спрашивает, перезапустить ли службу сейчас; изменения вступят в силу после следующего запуска службы, даже если перезапуск пропущен. Добавление доменов не гарантирует работу сайта или приложения.

- «Стратегии» — список стратегий, установка выбранной службой, временный ручной запуск winws.exe, детальный тест (в консоли), создание своей копии стратегии, импорт по коду zapret1:... и экспорт кодом, настройка повторов, позиции разделения, перекрытия и фейка стратегии.

- «Сеть и DNS» — DNS-настройки адаптеров, включение DoH (Cloudflare, Google, Quad9, AdGuard, Яндекс), возврат к DHCP и восстановление DNS из копии, сравнение DNS-провайдеров, снижение задержки и отмена сетевых изменений, проверка MTU, качество связи, режим игрового трафика и его порты.

- «Дополнительно» — диагностика и проверка голоса Discord в окне приложения, отчёт для поддержки, проверка обновлений, её автовключение и автоустановка (config.json -> updateFeed), режимы IP-фильтра, обновление списка IP и hosts, файлы подмены UDP (Discord/игры), пауза обхода, восстановление из резервной копии, перенос настроек из старой папки, еженедельная перепроверка, удаление установки, ярлык и классическое меню zapret.bat.

Закрытие панели не останавливает службу. Панель не меняет конфигурацию сама по себе: любое изменение — установка стратегии, смена фейков, DNS/DoH, hosts/IPSet, игровой трафик, удаление — требует явного подтверждения и выполняется в окне приложения с журналом. Перед перезапуском службы панель предупреждает о конфликтах и проверяет, что winws.exe действительно запустился. Классическое меню zapret.bat и консольные команды из разделов ниже остаются доступны как дополнительный способ управления.


3. АВТОПОДБОР СТРАТЕГИИ
-----------------------
Пункт меню 13 запускает проверку на текущем компьютере и текущем подключении. Количество проверяемых вариантов зависит от состава доступных и пользовательских стратегий; фиксированное число в инструкции намеренно не указывается.

По умолчанию проверяется доступность веб-endpoint'ов Discord, YouTube и WhatsApp. Любой HTTP-ответ, включая 403/404, считается ответом сервера; отсутствие HTTP-ответа — неуспехом. Причина каждого отказа (таймаут, DNS, сброс или TLS-ошибка) показывается в строке адреса. Если DNS не резолвит адреса, включите DoH (меню DNS или `zapret.ps1 dns doh cloudflare`) и повторите; для медленного канала время пробы задаётся параметром `-TimeoutSec` или увеличивается автоматически по калибровке при старте. До прогонов стратегий выполняется предпроверка: конфликтующие программы и доверие DNS (системные ответы сравниваются с DoH). При подмене DNS подбор предложит включить DoH и повторить проверку. В панели на странице результата есть кнопки «Включить DoH и повторить», «Повторить проверку» и «Отключить конфликтующие и повторить» — конфликтующие программы (VPN/прокси) отключаются с сохранением прежних настроек служб и включаются обратно кнопкой «Включить отключённые обратно». Это не проверка работы приложения целиком.

Для проверки передачи данных используйте `-CheckFreeze` или более подробный режим `-Deep`: проверяется получение полного диапазона 0–65535 (65 536 байт) хотя бы с одного из двух HTTPS-адресов. `-Deep` дополнительно проверяет HTTP, TLS 1.2 и TLS 1.3 и автоматически включает тест передачи. Результаты и отчёт сохраняются в logs\auto-select-*.txt.

Перед установкой Auto-Select повторно проверяет лидера и сравнивает успешные endpoint'ы/передачи. Если повторный результат нестабилен, установленная стратегия не будет заменена. При наличии рабочей службы нужен заметный выигрыш: минимум два дополнительных доступных endpoint'а, либо дополнительный сервис без потери общей доступности; при равном покрытии — повторно подтверждённый прирост скорости не менее 25% и 50 КБ/с. Если текущая стратегия не попала в проверяемый набор (например, это общая стратегия при узком `-Carrier`-подборе или быстрый поиск завершился раньше), программа отдельно проверяет её как базовый вариант. Если активную стратегию нельзя найти или измерить, install gate закрыт — непроверенное сравнение не считается улучшением. Отчёт в `logs\auto-select-*.txt` включает базовый результат, повторную проверку и решение install gate.

Если кандидат не устанавливается, Auto-Select восстанавливает прежний режим: работающую службу запускает снова, а если служба была остановлена, она остаётся остановленной. Известную вручную запущенную стратегию программа запускает повторно; если определить её не удалось, покажет команду для ручного запуска. При неопределённом состоянии службы тестирование прерывается до остановки процессов.

Команды из папки проекта:

   zapret.ps1 auto-select                  — обычный подбор
   zapret.ps1 auto-select -Fast            — сначала короткий список; если он не прошёл полностью, используется полный подбор
   zapret.ps1 auto-select -CheckFreeze     — дополнительно проверить передачу 64 КБ
   zapret.ps1 auto-select -Deep            — HTTP/TLS 1.2/TLS 1.3 и тест передачи
   zapret.ps1 auto-select -Install         — установить выбранный вариант без вопроса; после успеха также выполнить настройку hosts/IPSet без отдельного вопроса
   zapret.ps1 health-check                 — быстрая проверка всех эндпоинтов через текущий обход (только чтение)
   zapret.ps1 watchdog enable|disable|status — автозащита: фоновая проверка обхода каждые 4 часа и автовосстановление через автоподбор с защитой от ложных установок
   zapret.ps1 profile [all|discord-only|youtube-only|no-whatsapp] — профиль обхода: ограничить обход выбранными сервисами (без аргумента — показать текущий)
   zapret.ps1 speed-test                  — тест скорости скачивания через текущий обход (64 КБ с двух адресов)

`-Install` — явное согласие на установку и последующую настройку hosts/IPSet. Используйте его только если действительно хотите эти действия без интерактивного подтверждения. Если проверка не дала убедительного результата, сначала запустите диагностику и не устанавливайте вариант наугад.


ПРОФИЛЬ ОБХОДА И ТЕСТ СКОРОСТИ
--------------------
Профиль обхода (страница «Мои сайты» панели) ограничивает обход выбранными
сервисами: домены остальных сервисов из встроенного каталога временно
исключаются из обхода, ваши собственные записи в списке исключений сохраняются,
а профиль «Все сервисы» возвращает исходное поведение. Профили: all
(по умолчанию), discord-only, youtube-only, no-whatsapp. Это удобный
переключатель на основе доменов-подсказок, а не полный инвентарь сервиса:
отдельные CDN-адреса могут не попасть в список. После смены профиля
перезапустите службу кнопкой «Перезапустить службу» или ответьте «Да» в окне.

Тест скорости (кнопка «Тест скорости» на странице «Обзор» или
zapret.ps1 speed-test) измеряет скорость скачивания через текущее состояние
обхода: до 500 КБ/с — отлично, до 100 КБ/с — нормально, ниже — медленно.

Индикатор обхода в трее (Zapret-Tray.exe) обновляется автоматически каждые
5 минут: зелёный — обход работает, жёлтый — частично, красный — не работает,
серый — проверка или нет данных. Пункт «Обновить индикатор» обновляет значок
вручную; «Проверить обход» открывает подробности в консоли. Если обход
перестаёт работать (или снова начинает), трей показывает короткое уведомление.

ЕСЛИ WINWS.EXE НЕ ЗАПУСКАЕТСЯ
--------------------
Автоподбор и проверки показывают причину: код выхода winws, текст его вывода
(«windivert: error opening filter: …») и что делать. При сбое драйвера WinDivert
(коды 2, 3, 34, 53, 177, 577, 654, 1056, 1058, 1072, 1114, 1275) программа
сама удаляет устаревшую службу WinDivert (включая легаси WinDivert14) и повторяет
запуск. Если не помогло: перезагрузите компьютер, временно отключите антивирус
и удалите старые копии проекта — каждая копия ставит свою службу драйвера.

ДОКТОР УСТАНОВКИ
----------------
zapret.ps1 doctor — самопроверка установки: файлы, версии, блокировка файлов
антивирусом (Windows помечает скачанные файлы, и winws может не стартовать),
устаревшие службы WinDivert, согласованность службы обхода и списков.
zapret.ps1 doctor -Fix — то же самое, но снимает блокировку файлов и удаляет
устаревшие службы драйвера. zapret.ps1 doctor -Deep — дополнительно запускает
bin\WinProbe.exe: проба драйвера WinDivert напрямую с точным кодом ошибки.
Те же кнопки есть в панели: «Дополнительно» → «Проверка установки» и
«Проверка + ремонт».

ГОЛОС DISCORD: ПРОВЕРКА И РЕМОНТ
--------------------------------
Кнопка «Голос Discord: проверка и ремонт» (или zapret.ps1 voice-check fix)
не только проверяет путь голоса, но и чинит его: перезапускает обход
и перебирает UDP-фейки голоса, пока проверка не пройдёт. Если войс
подключается, но пинг в Discord ~5000 мс — кнопка «Сменить фейк голоса»
(zapret.ps1 voice-check next-fake): каждый нажатие берёт следующий фейк
и перезапускает обход; повторяйте, пока голос не станет нормальным.
zapret.ps1 voice-check — только диагностика без изменений.

РЕЗЕРВНАЯ КОПИЯ НАСТРОЕК
-------------------------
zapret.ps1 export-config — собирает ваши настройки, личные списки, IP-список
и выбранные фейки в один zip-файл (по умолчанию на Рабочий стол). Кнопка
«Резервная копия настроек» в панели делает то же самое. Вернуть всё обратно:
zapret.ps1 import-config <путь-к-zip> (или кнопка «Перенести настройки» —
она принимает и старую папку, и zip-архив копии). Перенос работает и между
компьютерами: создайте копию, на новой машине распакуйте свежую версию
и выполните import-config.

ЗАПАСНЫЕ СТРАТЕГИИ
------------------
Автоподбор запоминает до 5 проверенных вариантов. Если обход внезапно
откажет, автозащита сначала быстро переключится на следующий проверенный
вариант (zapret.ps1 fallback status — что сохранено; fallback off — отключить
быстрое переключение, тогда автозащита сразу запускает полный подбор).

Проверка сайта (страница «Мои сайты» или zapret.ps1 site-check <адрес>)
показывает, как сайт проходит через обход: попадает ли домен в списки
(или исключён из них, в том числе активным профилем), отвечает ли сервер
и скачиваются ли данные. Это быстрый способ понять, почему конкретный сайт
не открывается.

Автозапуск трея (кнопка «Автозапуск трея» на «Обзоре» или
zapret.ps1 tray-autostart enable|disable|status) — значок будет появляться
при каждом входе в Windows. Запись делается только для текущего пользователя
и не требует администратора.

4. МОБИЛЬНОЕ ПОДКЛЮЧЕНИЕ В АВТОНАСТРОЙКЕ (МЕНЮ 25)
----------------------------------------------------
Пункт 25 — единый мастер и для обычного, и для мобильного интернета. Сначала выберите обычный или мобильный интернет. Если выбрано мобильное подключение, мастер попросит выбрать оператора: МТС, МегаФон, Tele2/T2 или Йота. Автоматического определения SIM нет: до проверки подключите компьютер именно через эту SIM/eSIM, например по USB-модему или точке доступа телефона. Для обычного домашнего/офисного Wi-Fi или кабеля выбирайте обычный профиль.

CLI-вариант без интерактивного выбора оператора:

   zapret.ps1 auto-setup -Carrier mts -Fast
   zapret.ps1 auto-setup -Carrier megafon -Fast
   zapret.ps1 auto-setup -Carrier tele2 -Fast
   zapret.ps1 auto-setup -Carrier yota -Fast

Такой запуск сразу выбирает мобильный профиль, минуя вопросы о типе подключения и операторе. Для прямого подбора без мастера также доступны:

   zapret.ps1 auto-select -Carrier mts -Fast
   zapret.ps1 auto-select -Carrier megafon -Fast
   zapret.ps1 auto-select -Carrier tele2 -Fast
   zapret.ps1 auto-select -Carrier yota -Fast

Мобильный режим проверяет четыре узкие стратегии, веб-endpoint'ы Discord/YouTube/WhatsApp и получение 64 КБ. При быстром подборе программа переходит к следующему кандидату, если предыдущий не прошёл обязательные проверки. Если уже установлена другая стратегия, она при необходимости отдельно проверяется как baseline, но не становится carrier-кандидатом. Если ни один кандидат не подтвердит доступность всех трёх сервисов и передачу данных, новый вариант не устанавливается. Последний carrier-вариант записывается в `config.json` только после повторной проверки; он лишь задаёт приоритет следующего подбора и не устанавливается сам по себе. Поэтому предпочтение может сохраниться даже если вы позднее отказались от установки.

Профили экспериментальные. Результат одной SIM, региона или способа раздачи не переносится автоматически на другие условия; проверка сайтов не подтверждает работу мобильных приложений, входа, чатов и звонков. Профили не являются официальными рекомендациями операторов и не дают гарантии. Начиная с версии 2.1.4 обычные встроенные стратегии также включают домены WhatsApp; новая конфигурация применяется после переустановки стратегии. С версии 2.1.27 Telegram исключён из проверок и стратегий: обход блокировок Telegram Desktop (MTProto) не работает и больше не предлагается.

6. DNS, HOSTS И IPSET
---------------------
- Пункт 15 показывает DNS и позволяет включить DoH (Cloudflare, Google, Quad9, AdGuard или Yandex). Перед изменением сохраняется снимок прежних IPv4 DNS-настроек.
- `zapret.ps1 dns status` — показать DNS; `zapret.ps1 dns doh cloudflare` — запросить включение Cloudflare DoH; также доступны `google`, `quad9`, `adguard`, `yandex`.
- `zapret.ps1 dns rollback` — вернуть настройки из последнего DNS-снимка; `zapret.ps1 dns reset` — отдельно переключить DNS на автоматический DHCP. Это разные операции.
- Пункт 9 обновляет только управляемый блок записей zapret в системном файле hosts. Перед записью создаётся резервная копия `hosts.zapret-bak-*`. Пункт 19 может восстановить hosts из снимка, если он был создан.
- IPSet-фильтр имеет режимы `none` (не использовать список), `loaded` (использовать список) и `any` (не ограничивать фильтр списком; может затронуть больше трафика). После изменения фильтров может потребоваться перезапуск службы.
- `-Preview` показывает план без UAC, изменения системных настроек и создания rollback-снимка. Примеры: `ipset any -Preview`, `ipset-update -Preview`, `hosts-update -Preview`, `dns doh cloudflare -Preview`, `dns reset -Preview`, `dns rollback -Preview`, `dns benchmark -Preview`, `net-optimize -Preview`, `net-optimize -Revert -Preview`, `mtu-check -Preview`. Запускайте из папки проекта.
- Не все previews полностью офлайн: `dns benchmark -Preview` выполняет ICMP- и HTTPS-проверки пяти провайдеров, затем показывает план для самого быстрого доступного; `mtu-check -Preview` отправляет ICMP-запросы на `1.1.1.1`, чтобы измерить MTU. Эти проверки могут занять время и зависят от доступности ICMP/HTTPS, но не меняют настройки. `dns doh <провайдер> -Preview` показывает план без проверки провайдера и без регистрации DoH.
- Preview обновления IPSet и hosts может скачать данные во временный файл; исходные списки и hosts, резервные копии и rollback-снимки не заменяются. Чтобы применить план, повторите команду без `-Preview`; обычные DNS/сетевые изменения требуют прав администратора.

Если сайты не открываются, сначала проверьте `zapret.ps1 diagnostics`, `zapret.ps1 dns status` и выбранную стратегию. DoH может помочь при проблемах обычного DNS, но доступность самого DoH-провайдера зависит от сети.


7. ИГРЫ И ВРЕМЕННАЯ ПАУЗА
--------------------------
Игровой фильтр по умолчанию выключен. Если игра не требует обхода, не включайте его без необходимости. IPSet `any` охватывает более широкий трафик и может мешать обычным сайтам.

Пункт меню 22 или команда `zapret.ps1 pause [Минуты]` временно останавливает обход, а затем пытается восстановить прежний режим. Если число минут не указано, программа ждёт нажатия Enter; с числом минут ожидание можно завершить раньше клавишей. Допустимый таймер — 1–1440 минут.

При паузе и удалении WinDivert/WinDivert14 программа проверяет путь службы. Она останавливает и удаляет регистрацию драйвера только если путь указывает на подходящий файл WinDivert внутри папки `bin` этой установки. Службу с путём другой программы или нераспознанным путём программа оставляет, чтобы не задеть чужую установку.


8. ЕЖЕНЕДЕЛЬНАЯ ПЕРЕПРОВЕРКА И ОТКАТ
-----------------------------------
- Пункт 16 или `zapret.ps1 schedule-autoselect enable` создаёт задачу Windows на воскресенье, 03:30, с повышенными правами SYSTEM. Отключение: `zapret.ps1 schedule-autoselect disable`; состояние: `zapret.ps1 schedule-autoselect status`.
- Задача сначала проверяет текущий обход. Если все контрольные адреса доступны, завершает работу без перезапуска `winws.exe`. Если нужна полная проверка, она может временно остановить обход на время перебора и изменить выбранную стратегию. Отключите задачу, если автоматическая смена настроек вам не подходит.
- Пункт 19 или `zapret.ps1 rollback` восстанавливает доступные данные последнего снимка (например, стратегию, IPSet и hosts). Для DNS и сетевых твиков предусмотрены отдельные откаты.
- Пункт 23 включает DNS benchmark, сетевую оптимизацию, откат последнего сетевого снимка, проверку MTU и качества связи. Некоторые действия меняют системные настройки и требуют подтверждения; перед изменением создаются снимки там, где это предусмотрено.
- `zapret.ps1 net-optimize` применяет сетевые параметры с резервным снимком; `zapret.ps1 net-optimize -Revert` откатывает последнее сетевое изменение.
- `zapret.ps1 mtu-check` измеряет MTU по ICMP и предлагает применить результат. Потери пакетов и фильтрация ICMP могут сделать оценку неточной или невозможной. `zapret.ps1 mtu-check -Preview` также выполняет ICMP-измерение и показывает текущий интерфейс и планируемое значение, но ничего не записывает и не создаёт rollback-снимок.
- Preview сетевых команд (`net-optimize -Preview`, `net-optimize -Revert -Preview`, DNS-команды и MTU) не меняет системные настройки и не создаёт rollback-файлы. Реальное применение DNS, сетевых твиков и MTU требует администратора; возврат DNS: `zapret.ps1 dns rollback`, сетевых параметров/MTU: `zapret.ps1 net-optimize -Revert`.
- `zapret.ps1 ping-test` измеряет задержку/потери до шлюза, 1.1.1.1 и discord.com. Это диагностика, а не гарантия качества соединения.


9. МОИ САЙТЫ, СТРАТЕГИИ И ПЕРЕНОС НАСТРОЕК
-------------------------------------------
- Пункт 20 или `zapret.ps1 domain add example.com` добавляет домен в личный список обхода; `domain exclude example.com` — в список исключений; `domain remove example.com` — удаляет точное доменное имя из обоих личных списков; `domain list` — показывает их. Можно передать полный URL: программа извлечёт домен.
- `zapret.ps1 discover-domains` очищает системный DNS-кэш Windows, после чего попросит открыть нужный сайт/игру и предложит добавить найденные домены. Используйте только если понимаете, что команда очищает DNS-кэш.
- Пункт 21 позволяет клонировать встроенную стратегию или импортировать/экспортировать её кодом `zapret1:...`. Импорт проверяет структуру и допустимые аргументы; не запускайте данные из неизвестного источника.
- Пункт 18 или `zapret.ps1 import-config <путь-к-старой-папке>` переносит поддерживаемые настройки и пользовательские файлы из другой установки. Проверьте источник перед переносом.
- Пункт 17 или `zapret.ps1 support-bundle` создаёт ZIP с диагностикой, DNS/статусом, настройками и журналами. По умолчанию фильтр маскирует профильные пути/имя пользователя, частные IP, MAC, e-mail и распространённые поля токенов/паролей; пользовательские стратегии не включаются. Оригинальные журналы не меняются. `zapret.ps1 support-bundle -Preview` покажет состав архива без сбора данных. `-IncludeSensitive` отключает редактирование и может добавить пользовательские стратегии — используйте только осознанно. Автофильтр не гарантирует обнаружение всех секретов: всё равно проверьте ZIP до отправки в публичный issue.


10. ПОЛНОЕ УДАЛЕНИЕ
-------------------
Из меню: выберите пункт 2 и подтвердите удаление службы. Затем программа отдельно спросит про управляемый блок hosts; пустой ответ на этот второй вопрос означает «да».

Команды из папки проекта:

   zapret.ps1 uninstall
       — удаляет службу zapret и задачу еженедельной перепроверки; если есть управляемый блок hosts, задаёт вопрос (пустой ответ — удалить блок).

   zapret.ps1 uninstall -RemoveHostsBlock
       — то же, но явно удаляет управляемый блок hosts без вопроса.

Перед удалением блока hosts создаётся резервная копия. Если служебные маркеры блока повреждены или несбалансированы, программа отказывается менять hosts; исправьте лишнюю строку-маркер вручную или восстановите резервную копию.

Перед удалением служба `zapret` останавливается и проверяется; регистрация удаляется только после подтверждения остановки. Затем программа завершает `winws.exe` и проверяет, что процессов не осталось. Если Windows не смогла остановить или удалить службу, программа сообщит об ошибке вместо ложного сообщения об успехе; если служба помечена к удалению, закройте `services.msc` и при необходимости перезагрузите Windows.

При удалении WinDivert/WinDivert14 проверяется путь `bin` текущей установки и путь, сохранённый в службе `zapret` (например, при переносе программы из старой папки). Сторонние или нераспознанные драйверные службы остаются нетронутыми. После удаления можно убрать папку проекта; не удаляйте папки/драйверы других программ.

12. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
---------------------------
1. Запустите `zapret.ps1 diagnostics` и сохраните вывод/логи.
2. Проверьте доступ в интернет, DNS (`zapret.ps1 dns status`) и результат Auto-Select.
3. Проверьте, что адрес нужного сайта есть в списке доменов/IP, и что игра не попала под чрезмерно широкий фильтр.
4. Если не помогло — создайте `zapret.ps1 support-bundle`, проверьте ZIP на личные данные и приложите к issue:
   https://github.com/Flowseal/zapret-discord-youtube/issues
5. Не отправляйте приватные данные, пароли, файлы профиля/браузера и журналы без предварительной проверки.

Если не подключается голос Discord (войсы): выполните `zapret.ps1 voice-check` (или кнопку «Проверка голоса Discord» в панели, раздел «Дополнительно»). Проверка покажет, проходит ли сигнальный канал и UDP через активный фейк, есть ли конфликты с другими обходами/VPN, и подскажет, сменить фейк (меню 7) или убрать конфликтующую программу.

Если увидите сообщение о повреждённых маркерах hosts, программа намеренно не изменит файл. Откройте `C:\Windows\System32\drivers\etc\hosts`, проверьте строки `# >>> zapret-discord-youtube (managed) >>>` и `# <<< zapret-discord-youtube (managed) <<<`, затем восстановите корректный файл/резервную копию и повторите действие.

Последнее обновление инструкции: 2026-11-21 (версия проекта 2.9.6; графическая панель Zapret-Control — раздел 2 — покрывает весь функционал консольного меню).
