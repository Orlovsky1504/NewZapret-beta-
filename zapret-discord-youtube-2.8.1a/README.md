## ⚙️Использование

1. Включите Безопасный DNS (Secure DNS)
    * Или просто выполните `zapret.ps1 dns doh cloudflare` — см. FAQ «Обход запущен, но сайты всё равно не открываются»
    * В Chrome - "Использовать безопасный DNS", и выбрать поставщика услуг DNS (выбрать вариант, отличный от варианта "Поставщик по умолчанию")
    * В Firefox - "DNS через HTTPS", выбрать режим "Персональный", затем "Выбрать провайдера/поставщика" и вписать URL поставщика вручную. Например, можно использовать `https://dns.google/dns-query` (т.к. поставщик Cloudflare может быть заблокирован)
    * В Windows 11 поддерживается включение Secure DNS прямо в настройках ОС - [инструкция тут](https://remontka.pro/dns-over-https-windows-11/). Рекомендуется, если вы пользуетесь Windows 11
    * Если у вас роутер Keenetic, включите в настройках роутера опцию "Транзит запросов". Отключение этой опции может привести к проблемам при настройке и использовании Secure DNS на компьютере

2. Скачайте архив (zip/rar) со [страницы последнего релиза](https://github.com/Flowseal/zapret-discord-youtube/releases/latest)

3. Зайдите в свойства скачанного архива и поставьте галочку "Разблокировать". Если вы используете архиватор 7-Zip или PeaZip, этот шаг можно пропустить

4. Распакуйте содержимое архива по пути, который не содержит кириллицу/спец. символы

5. Дважды кликните по **`zapret.bat`** — классическое меню, или по **`Zapret-Control.exe`** — отдельную панель с графическим интерфейсом (приложение с иконкой; `Zapret-Control.bat` — запасной вариант запуска). Панель покрывает весь основной функционал меню: стратегии (выбор, установка, ручной запуск, свои стратегии), DNS/DoH и сетевые инструменты, игровые порты, домены, фейки, IPSet/hosts, диагностику, паузу, откат, перенос настроек и удаление. Панель не заменяет `zapret.bat`: оба способа управления работают с одной установкой. При первом запуске панель предложит создать ярлык **«Zapret Control»** с иконкой — он открывает приложение сразу, без консольного окна.

   В панели `Zapret-Control` автонастройка и все действия работают целиком внутри окна: выбор типа подключения и оператора, проверка с живым журналом и явные кнопки согласия — консоль не открывается.

   Откроется меню. Основные действия:
   * **Самый простой путь**: `25. Guided Auto-Setup` — спросит, обычный у вас интернет или мобильный; для мобильного попросит выбрать оператора. Затем проверит стратегии и отдельно запросит согласие на установку и настройку; пункт `13. Auto-Select Best Strategy` остаётся для подбора без мастера
   * Вручную: `12. Run Strategy Tests` -> `Standard tests` -> `All configs`
   * Поставить на автозапуск: `1. Install Service` -> *выбираете подходящую стратегию*

   **Всё управление теперь в одном месте** — устанавливать и удалять отдельные `general*.bat` больше не нужно.

Для обновления существующей установки скачайте ZIP релиза вместе с `SHA256SUMS.txt`, проверьте SHA-256 и распакуйте архив в отдельную временную папку. Запустите оттуда `Update-Zapret.bat`, выберите исходный ZIP и прежний каталог установки. Не распаковывайте ZIP поверх работающей установки: обновлятор оставляет её на том же пути, сохраняет пользовательские файлы и не начинает замену, если `WinDivert64.sys` занят.

```

Zapret-Control.bat  — запасной запуск панели (compatibility fallback)

Zapret-Control.ico  — иконка приложения (ярлык «Zapret Control» и окно панели)
zapret.ps1          — движок: меню + CLI-режим (`zapret.ps1 <команда>`)
service.bat         — устаревший алиас на zapret.bat (оставлен для совместимости)
Update-Zapret.bat   — запуск безопасного обновления в существующий каталог
Update-Zapret.ps1   — проверка архива, сохранение пользовательских файлов и откат при сбое
strategies.json     — база стратегий (единое место вместо 22 копий .bat файлов)
src\Zapret.psm1     — совместимый входной модуль; загружает и экспортирует функции из src\parts\
src\parts\         — обслуживаемые части модуля: runtime, стратегии, IPSet/hosts, diagnostics, Auto-Select, DNS/network, support, rollback
utils\test zapret.ps1 — утилита проверки стратегий (запускается из меню или `zapret.ps1 test`)
utils\targets.txt   — список целей для проверки доступности
tests\Test-Build.ps1 — проверка целостности сборки (стратегии, ссылки на bin\lists, синтаксис)
lists\              — списки доменов и ipset (пользовательские *-user.txt создаются автоматически)
bin\                — winws.exe, WinDivert, фейки TLS/QUIC (не редактируйте без понимания)
config.json         — ваши настройки (создаётся при первом запуске; настройки мигрируют из старых `utils\*.enabled`)
logs\               — логи работы (создаётся при использовании)
```

## 🖥️Меню и CLI

Пункты меню (`zapret.bat`):

- **Install Service** — установка выбранной стратегии в автозапуск (служба `zapret`, services.msc)
- **Remove Services** — останавливает и проверяет службу `zapret`, удаляет её регистрацию, завершает `winws.exe` и проверяет, что процессов не осталось; снимает задачу еженедельной перепроверки и спрашивает про управляемый блок `hosts` (Enter = удалить). `WinDivert`/`WinDivert14` удаляются только если путь ведёт в `bin` текущей установки или папки, на которую указывала служба `zapret` (поддерживается перенос/обновление из старой папки); чужие и нераспознанные драйверы остаются. При ошибке остановки/удаления программа сообщает о неполной очистке, а не показывает успех. В CLI `zapret.ps1 uninstall -RemoveHostsBlock` удаляет управляемый блок без вопроса.
- **Check Status** — состояние службы, WinDivert, winws.exe, ipset, игрового фильтра
- **Game Filter** — обход для игр и сервисов с портами выше 1023 (TCP/UDP, диапазоны настраиваются)  
  **После переключения требуется перезапуск стратегии/службы.**
- **IPSet Filter** — режим сопоставления ipset-all.txt: `none` / `loaded` / `any`
- **Auto-Update Check** — вкл/выкл автоматическую проверку обновлений
- **Replace Active Fakes** — замена активных UDP-фейков (Discord/Game) другими из папки `bin`
- **Update IPSet List** — скачать свежий `ipset-all.txt` (с проверкой содержимого и .bak-копией)
- **Update Hosts File** — установить рекомендуемые записи в `hosts` автоматически  
  Записи добавляются маркированным блоком `# >>> zapret-discord-youtube (managed) >>>`, при обновлении блок заменяется целиком (без дубликатов), перед изменением создаётся резервная копия.
- **Check for Updates** — проверка новой версии (страничка релиза откроется в браузере)
- **Run Diagnostics** — диагностика типовых причин неработоспособности (+ очистка кэша Discord); сверяет часы с HTTPS `Date`, проверяет IPv6 Dual-Stack и предупреждает, если HVCI может блокировать WinDivert
- **Проверка голоса Discord** — кнопка «Проверка голоса Discord» в разделе «Дополнительно» панели и команда `zapret.ps1 voice-check`: проверяет сигнальный TCP до `discord.media`, UDP-пробы с активным фейком (`bin\ACTIVE_DISCORD_UDP.bin`), STUN до Discord и базовую UDP-проверку Google STUN, а также конфликты с другими обходами и VPN (Killer, GoodbyeDPI, чужой `winws`, AdGuard, WireGuard/WARP и подобные). Проверка только читает состояние и ничего не меняет
- **Run Strategy Tests** — проверка всех стратегий: сайты из `utils/targets.txt` (Standard tests) или DPI-чекеры (TCP 16-20)
- **Auto-Select Best Strategy** — компьютер по очереди запускает стратегии, проверяет веб-endpoint'ы Discord, YouTube и WhatsApp и показывает лидера (отчёт — `logs/auto-select-*.txt`). Это проверка сетевых endpoint'ов, а не входа в аккаунт, звонков или работы приложений. Любой HTTP-ответ (включая 403/404) засчитывается как ответ сервера; отсутствие ответа показывается как «нет HTTP-ответа» с причиной (таймаут, DNS, сброс или TLS-ошибка); по итогам подбора выводится подсказка — например, включить DoH при проблемах с DNS. Бюджет пробы калибруется живым замером рукопожатия: медленные каналы получают больше времени автоматически. До начала подбора выполняется предпроверка: конфликтующие программы (VPN/WARP/GoodbyeDPI/AdGuard) и доверие DNS — системные ответы сравниваются с DoH, и подмена DNS обнаруживается до прогонов стратегий. При проблемах с DNS подбор сразу предлагает включить DoH и повторить — в панели это кнопка «Включить DoH и повторить» на странице результата; там же есть кнопки «Повторить проверку» и «Отключить конфликтующие и повторить» (конфликтующие VPN/прокси-программы отключаются с сохранением прежних настроек служб и включаются обратно одной кнопкой). Перед установкой лидер запускается и проверяется повторно: меняющийся набор доступных endpoint'ов или 64-КБ transfer-целей блокирует смену. Для уже установленной стратегии требуется значимый выигрыш — минимум +2 endpoint'а, либо +1 сервис без потери общей доступности; при одинаковом покрытии принимается только повторённый прирост скорости не менее 25% и 50 КБ/с. Сомнительный/минимальный выигрыш оставляет текущую стратегию. `-CheckFreeze` проверяет передачу всех 65 536 байт диапазона `0-65535` хотя бы с одного из двух HTTPS-серверов; `-Deep` включает её автоматически. При равном покрытии скорость выше 200 КБ/с влияет на ранжирование.
- **Guided Auto-Setup (меню 25)** — мастер сначала спрашивает, используется ли обычный (домашний/офисный Wi-Fi или кабель) или мобильный интернет. Для мобильного подключения он предлагает выбрать МТС, МегаФон, Tele2/T2 или Йоту и запускает узкий подбор для этого оператора; компьютер должен уже быть подключён через соответствующую SIM (например, USB-модем или точку доступа). Мобильный подбор проверяет доступность Discord, YouTube и WhatsApp и передачу 64 КБ; новый вариант не устанавливается, если обязательные проверки не пройдены. Профили экспериментальные: проверка сайтов не подтверждает вход, сообщения или звонки в самих приложениях и не гарантирует работу у оператора. После подбора обычного или мобильного профиля мастер спрашивает перед установкой службы (пустой ответ — «нет»), затем отдельно спрашивает об обновлении управляемого `hosts` и IPSet (также «нет» по умолчанию). Еженедельная задача предлагается отдельно. DNS/DoH и системные сетевые параметры не меняются. `zapret.ps1 auto-setup -Carrier <mts|megafon|tele2|yota>` сразу задаёт мобильный профиль без первого вопроса; `-Install` — явное согласие установить проверенный вариант и выполнить настройку hosts/IPSet без вопросов о применении (выбор типа подключения остаётся, если не задан `-Carrier`), `-EnableSchedule` явно включает задачу, а `-NoInteractive` только проверяет и ничего не применяет.
- Для прямого мобильного подбора без мастера остаётся CLI `zapret.ps1 auto-select -Carrier <mts|megafon|tele2|yota> -Fast`; пункт меню отдельно выбирать не нужно.
- **WhatsApp в стратегиях (2.1.4)** — стандартный список доменов включает веб/API-домены WhatsApp. Это помогает только при DPI-фильтрации, а не при блокировке IP на уровне соединения; адреса для звонков/медиа WhatsApp могут быть динамическими. Для применения новой конфигурации после обновления ZIP переустановите выбранную стратегию.
- **Telegram исключён (2.1.27)** — обход блокировок Telegram Desktop (MTProto) не работает и больше не предлагается: цели Telegram убраны из Auto-Select и проверок, правила и IP-подсети Telegram удалены из стратегий и списков, рекомендация «Telegram» удалена из «Моих сайтов». Файл `lists/ipset-telegram.txt` оставлен пустым только для совместимости со старыми пользовательскими стратегиями.
- **DNS / Secure DNS (DoH)** — показать DNS по каждому адаптеру, включить DoH Cloudflare / Google / Quad9 / AdGuard / Yandex; перед изменением сохраняется DNS-снимок, вернуть прежние настройки можно через `dns rollback` (а `dns reset` по-прежнему включает DHCP)
- **Network & Ping Tools (меню 23)** — подменю для DNS benchmark, сетевой оптимизации, проверки MTU и качества линии; команды: `dns benchmark`, `net-optimize [-Revert]`, `mtu-check`, `ping-test`
- **DNS benchmark** — три ICMP-пинга по IPv4 каждого провайдера плюс три HTTPS-проверки DoH endpoint; таблица по провайдеру/статусу/средней задержке (HTTPS-задержка служит резервной, если ICMP фильтруется) и предложение применить самый быстрый доступный вариант. DNS сохраняется в `logs/rollback-dns-*.json`; откат: `zapret.ps1 dns rollback`
- **Network optimize** — `zapret.ps1 net-optimize` сохраняет `logs/rollback-net-<timestamp>.json`, затем выставляет TCP- и Multimedia SystemProfile-твики и включает RSS. `zapret.ps1 net-optimize -Revert` восстанавливает снимок последнего сетевого изменения
- **MTU check** — `zapret.ps1 mtu-check` бинарным поиском проверяет payload 1200–1472 байта до `1.1.1.1`, повторяет неудачную пробу один раз, показывает текущий MTU активного интерфейса и предлагает применить измеренное значение через `netsh`; перед изменением создаётся сетевой rollback-снимок. ICMP-фильтрация/потери могут сделать оценку недоступной или неточной. Откат сетевого изменения: `zapret.ps1 net-optimize -Revert` или меню 23 → 3
- **Ping / line quality** — `zapret.ps1 ping-test` делает по 10 замеров до шлюза, `1.1.1.1` и `discord.com`, показывает min/avg/max/jitter/loss; потери или джиттер выше 10 мс до шлюза могут указывать на проблемы Wi‑Fi/кабеля
- **Weekly Auto Re-Check** — еженедельно (вс, 03:30), без остановки обхода проверяет, что всё открывается; если нет — прогоняет стратегии и ставит лучшую — обход продолжает работать, даже когда провайдеры меняют фильтры
- **Проверка пути запуска** — при старте инструмент проверяет путь на кириллицу, пробелы, спецсимволы и `OneDrive`; при найденных проблемах предлагает автоматически перенести папку в `C:\zapret` с перезапуском оттуда
- **Support Bundle** — `zapret.ps1 support-bundle` (или меню `17`): один ZIP на Рабочем столе — read-only диагностика, DNS/статус, config, последний Auto-Select-отчёт и свежий лог. По умолчанию маскируются профильное имя/пути, приватные IPv4/IPv6, MAC, e-mail и распространённые поля токенов/паролей; `strategies-user.json` исключён. Оригинальные логи не редактируются. Перед сбором покажите состав: `zapret.ps1 support-bundle -Preview`. `-IncludeSensitive` — явный отказ от редактирования (включая пользовательские стратегии, если есть); просмотрите ZIP вручную перед отправкой. Фильтр best-effort и не гарантирует обнаружение каждого секрета.
- **Preview системных изменений** — команды с `-Preview` только показывают план, права и откат; они не применяют настройки и не требуют UAC. Например: `ipset any -Preview`, `ipset-update -Preview`, `hosts-update -Preview`, `dns doh cloudflare -Preview`, `dns reset -Preview`, `dns rollback -Preview`, `dns benchmark -Preview`, `net-optimize -Preview`, `net-optimize -Revert -Preview`, `mtu-check -Preview`. Preview IPSet/hosts скачивает и валидирует данные во временных файлах, но не меняет установленные файлы. Для применения повторите команду без `-Preview`; изменения DNS, системного `hosts`, IPSet и сетевых твиков требуют администратора, создают rollback-снимок там, где предусмотрено, и печатают способ отката.
- **Миграция настроек** — `zapret.ps1 import-config <путь к старой папке>` (или меню `18`): переносит `config.json`, `*-user.txt`, `ipset-all.txt` и `ACTIVE_*.bin` из старой установки и переустанавливает службу с прежней стратегией
- **Проверка DoH-провайдера** — перед включением DoH (`dns doh ...`) выполняется HTTPS-проверка; если endpoint заблокирован, инструмент предлагает другой доступный вариант из Cloudflare / Google / Quad9 / AdGuard / Yandex
- **Авто-перезапуск службы** — после изменения Game Filter / IPSet / замены фейков инструмент предлагает сразу перезапустить службу zapret ([Y/n])
- **Мои сайты** — `zapret.ps1 domain add|exclude|remove|list` (меню `20`): добавление, исключение и удаление доменов, открытие списков в Блокноте и сброс к шаблонам. В пункте `8` есть рекомендации для YouTube, Discord, WhatsApp, Instagram, Facebook, TikTok, X и Twitch: перед добавлением показываются домены и запрашивается подтверждение; действующие исключения не обходятся. Рекомендации не гарантируют доступность. `discover-domains` очищает DNS-кэш, собирает домены посещённого сайта/игры и предлагает добавить выбранные
- **Умная еженедельная перепроверка** — если текущая стратегия по-прежнему открывает всё, задача завершается за секунды, не трогая winws.exe (пересоздайте задачу через `schedule-autoselect disable` + `enable`)
- **Rollback** — `zapret.ps1 rollback` (меню `19`): откат к прошлому рабочему состоянию (стратегия + ipset + hosts) в один шаг; снимок сохраняется автоматически перед каждой сменой
- **Clone Strategy** — `zapret.ps1 clone-strategy general my-general` (меню `21`): своя стратегия в `strategies-user.json`, тюнинг repeats / split-pos / seqovl / фейков через конструктор в меню
- **Обмен стратегиями** — `export-strategy <id>` выдаёт однострочный код `zapret1:...`; `import-strategy <код> [-NewId <id>]` проверяет формат (лимит 16 КБ), структуру и безопасные аргументы. Импорт и экспорт также доступны в меню `Clone Strategy`
- **Pause Bypass** — `zapret.ps1 pause [Minutes]` (меню `22`): временно останавливает службу/процесс и выгружает принадлежащие этой установке драйверы WinDivert (их записи удаляются только при совпадении пути с `bin`). Затем восстанавливает прежнюю стратегию; без времени ждёт Enter, таймер можно завершить клавишей
- **Первый запуск** — если ещё нет `config.json` и службы zapret, меню предлагает запустить Auto-Select (по умолчанию — да)
- **Авто-ротация логов** — файлы старше 14 дней удаляются, в `logs\` не больше 20 файлов

То же самое доступно из командной строки (например, из скриптов и планировщика):

## ☑️Распространенные вопросы и проблемы

### После запуска ничего не происходит

- После запуска стратегии (`zapret.bat` -> `run` или двойным кликом) должен открыться winws.exe (обход), который можно увидеть в области уведомлений.  
Если этого не произошло, то см. [#522](https://github.com/Flowseal/zapret-discord-youtube/issues/522)

### Как подобрать стратегию автоматически?

Меню → `13. Auto-Select Best Strategy` (или `zapret.ps1 auto-select`). Инструмент:

1. По очереди запускает доступные стратегии из `strategies.json` и пользовательских настроек
2. Проверяет веб-endpoint'ы Discord (main/gateway/CDN/updates), YouTube и WhatsApp
3. Ранжирует стратегии по числу открытых целей; при `-CheckFreeze` проверяет полную передачу 64 КБ, измеряет среднюю скорость и при равном покрытии ставит варианты быстрее 200 КБ/с выше
4. Показывает таблицу результатов, сохраняет отчёт в `logs/auto-select-*.txt`
5. По желанию ставит победителя как службу автозапуска и сразу же предлагает обновить блок в `hosts` и свежий `ipset-all.txt` (с резервными копиями) — чтобы обход работал из коробки
6. По желанию включает **еженедельную перепроверку** (`zapret.ps1 schedule-autoselect enable`) — что перестаёт работать со временем, чинится само

Измерение делается **с вашего ПК и вашего провайдера** — поэтому результат индивидуален для каждой машины/сети, универсально «лучшей» стратегии не существует. Если провайдер зарежет все стратегии, инструмент честно об этом скажет и предложит запустить диагностику.

### Обход запущен, но сайты всё равно не открываются

В большинстве таких случаев виноват **подмена DNS (DNS-poisoning)**: провайдер подменяет ответы DNS на заблокированные домены. Обход это не лечит — нужен зашифрованный DNS. Проверка и лечение одной командой:

```
zapret.ps1 dns status          # посмотреть, какой DNS сейчас у каждого адаптера
zapret.ps1 dns doh cloudflare  # включить DoH (доступны также google, quad9, adguard, yandex)
zapret.ps1 dns rollback        # вернуть DNS, который был до последней настройки DoH
zapret.ps1 dns reset           # отдельно: вернуть автоматический DNS (DHCP)
```

`dns doh` регистрирует шаблон DoH в Windows 11 (если система поддерживает) и прописывает DNS выбранного провайдера для активных физических адаптеров. Перед изменением создаётся `logs/rollback-dns-*.json`; `dns rollback` возвращает сохранённые IPv4 DNS-адреса и DHCP/static-режим, а `dns reset` намеренно переводит адаптеры на DHCP. Регистрация DoH-шаблона в Windows может остаться после отката; она применяется только если текущий DNS-сервер совпадает с зарегистрированным адресом. Дополнительно включите Secure DNS в браузере (Chrome → Настройки → Безопасный DNS).

### Ни одна стратегия не подходит
- Запустите командную строку от имени администратора
- Последовательно введите команды в консоль:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не работает Telegram

Начиная с версии 2.1.27 Telegram исключён из продукта: проверки и стратегии больше не нацелены на Telegram, обход блокировок Telegram Desktop (MTProto) не поддерживается.

### Не подключается голос Discord (войсы)
Запустите **`zapret.ps1 voice-check`** (или кнопку «Проверка голоса Discord» в панели). Проверка покажет: проходит ли сигнальный канал TCP до `discord.media`, отвечают ли UDP-пробы через активный фейк и STUN, работает ли UDP в целом (базовая проверка Google STUN) и нет ли конфликтующих программ (Killer, GoodbyeDPI, VPN/WARP, AdGuard, чужой `winws`).

- Если UDP не проходит вообще — уберите конфликтующую программу из списка и повторите проверку.
- Если UDP работает, но к Discord не проходит — смените фейк для Discord (`Replace Active Fakes` в меню или `zapret.ps1 fakes discord <имя-файла>` из `bin`), перезапустите службу и повторите проверку.
- После смены фейков дождитесь подтверждения «Служба zapret перезапущена»: если служба запустилась, но `winws.exe` не работает, программа теперь сообщает об этом и перечисляет конфликты.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии со временем могут переставать работать.**
> Определенная стратегия может работать какое-то время, но со временем она может переставать работать из-за обнаружения.
> В репозитории представлены множество различных стратегий для обхода. Если ни одна из них вам не помогает, то вам необходимо создать новую, взяв за основу одну из представленных здесь и изменив её параметры в `strategies.json`.
> Информацию про параметры стратегий вы можете найти [тут](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте, чтобы не было ошибок в `zapret.bat` -> `Run Diagnostics`

- Убедитесь, что адрес ресурса записан в списках доменов или IP

- Проверьте другие стратегии (**`ALT`**/**`FAKE`** и другие)

- Попробуйте полную переустановку (см. раздел ниже)

- См. [#765](https://github.com/Flowseal/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?

`Remove Services` останавливает и проверяет службу `zapret`, удаляет её регистрацию, завершает `winws.exe` и убеждается, что процессов не осталось; также удаляет задачу Windows `Zapret-AutoSelect` (если она была настроена). Если остановка/удаление не удались, команда сообщает об ошибке, а не о полном успехе. При очистке `WinDivert`/`WinDivert14` учитывается путь `bin` из зарегистрированной службы `zapret`, в том числе старой папки после переноса/обновления. Служба драйвера из другой программы или с нераспознанным путём остаётся нетронутой. Удаление управляемого блока из `hosts` подтверждается отдельно (пустой ответ — «да»), перед правкой создаётся резервная копия `hosts.zapret-bak-*`.

- Сохраните ресурсы/данные, которые вы сами добавляли
- Перезапустите устройство
- `zapret.bat` -> `Remove Services`
- `zapret.bat` -> `Run Diagnostics` (если есть ошибки - устраните их) -> в конце Y
- Удалите папку с запретом
- Скачайте последнюю версию [со страницы релизов](https://github.com/Flowseal/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите пкм по архиву -> свойства. Если снизу справа есть галочка разблокировать, то нажмите на неё -> применить -> ОК
- Распакуйте в новую папку в корне диска (без спец. символов и пробелов)
- Запустите **`zapret.bat`** -> `Run Strategy Tests` -> попробуйте разные стратегии
- Как найдёте рабочую стратегию: `zapret.bat` -> `Install Service` -> выбираете нужную

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Telegram больше не поддерживается (с версии 2.1.27): обход блокировок Telegram Desktop (MTProto) не работает, проверки и стратегии не нацелены на Telegram.

### Не работает WhatsApp

- В версии 2.1.4 стандартные стратегии обрабатывают домены WhatsApp. После обновления ZIP переустановите выбранную стратегию.
- Если сообщения работают, но медиа/звонки нет, сервис может использовать дополнительные динамические адреса, не покрытые доменным списком.

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/174/174872.png" height=18 /> Spotify

- С помощью zapret нельзя починить Spotify, он сам заблокировал российских пользователей. В Discussions можно найти другие способы починки Spotify, но к zapret они не имеют никакого отношения, и помощь по ним в issues не предоставляется.

### Не работают игры

Есть много разных игр. Исследовать и чинить каждую из них нет возможности.

Наиболее универсальный рецепт такой:
- через `zapret.bat` обновите ipset (`Update IPSet List`) и включите `Game Filter` (`TCP and UDP`)
- если это не поможет, то попробуйте также включить `IPSet Filter` в `any`

Но помните, что при включении `ipset any` появятся проблемы с открытием многих сайтов. Чтобы этого избежать, не используйте `ipset any` на постоянной основе. Вместо этого нужно выяснить все IP-адреса и домены, которые используются игрой, и добавить их в `ipset-all.txt` и в `list-general-user.txt` соответственно.

Игра работает, но большой пинг? Выясните всё то же самое, но вместо этого добавьте IP-адреса в `ipset-exclude-user.txt`, а домены в `list-exclude-user.txt`

Если и это не помогло, создайте ветку обсуждений в разделе [Discussions](https://github.com/Flowseal/zapret-discord-youtube/discussions) (не в issues) и ждите помощи от других игроков.

### Повышает ли zapret пинг в играх? Может ли он улучшить маршрутизацию?

Честные ответы:

**Пинг не повышается.** Обход работает на уровне **вашего компьютера**: winws перехватывает и «разбивает» только те пакеты, которые совпали с фильтрами (Discord/YouTube/Google и т.п.). Игровой трафик по умолчанию **вообще не перехватывается** (игровой фильтр выключен — `1024-65535` в заглушке). Пакет либо не изменился вовсе, либо модификация локальная и занимает микросекунды — задержка не чувствуется. Если всё же хотите гарантированно не трогать игры, убедитесь, что `Game Filter` выключен (`zapret.ps1 game-filter off`).

**Маршрутизацию zapret изменить не может — и не обещает этого.** Это не VPN: трафик идёт по тому же маршруту вашего провайдера, просто с «обманом» DPI-оборудования на входе/выходе (замена SNI, разбивка пакетов и т.д.). Ни один инструмент уровня пакета не способен перевыбрать магистраль, peering или уменьшить количество хопов. Обещания «улучшим маршрутизацию без VPN» от любых программ такого класса — маркетинг.

**Улучшить пинг через обход тоже нельзя** — минимизировать поможет только другой маршрут (VPN в нужной стране, другой провайдер) или более близкие игровые серверы. zapret может стать «менее вредным» для пинга, чем VPN (нет лишнего хопа в другую страну), но не «лучше», чем напрямую.

**Почему YouTube может не заработать, даже с самой лучшей стратегией.** Ограничения могут быть устроены не как SNI-блокировка, а как замедление (throttling) по полосе. Обход SNI не восстанавливает урезанную скорость — такое обойти нельзя без внешнего сервера. Нарушение блокировки по спискам (SNI/IP) — обойти можно, и `Auto-Select` подберёт рабочую стратегию.

## 🗒️Добавление адресов прочих ресурсов

Список адресов для обхода можно расширить, добавляя их в:
- **`list-general-user.txt`** для доменов (поддомены автоматически учитываются)
- **`list-exclude-user.txt`** для исключения доменов (например, если айпи сети указан в `ipset-all.txt`, но конкретный домен из этой сети не надо фильтровать)
- **`ipset-all.txt`** для IP и подсетей
- **`ipset-exclude-user.txt`** для исключения IP и подсетей
  - Файлы **`*-user.txt`** автоматически создадутся при первом запуске

## 🔐Безопасность

- Скачивайте только со [страницы релизов](https://github.com/Flowseal/zapret-discord-youtube/releases). В релиз приложен `SHA256SUMS.txt`; сборщик создаёт и проверяет манифест, а workflow перед публикацией автоматически выполняет `sha256sum --check SHA256SUMS.txt`. Linux/macOS: `sha256sum --check SHA256SUMS.txt`; Windows PowerShell: сравните `Get-FileHash .\zapret-discord-youtube-<версия>.zip -Algorithm SHA256` с SHA256-строкой ZIP из манифеста.
- `zapret.bat` -> `Run Diagnostics` проверяет Authenticode-подписи бинарников (`winws.exe`, `WinDivert.dll/.sys`, `cygwin1.dll`): `HashMismatch` = файл подменён после подписания — скачайте заново.
- Инструмент намеренно НЕ имеет автоматического самообновления кода: обновление — только скачиванием с проверенной страницы релиза.
- Подробнее: [SECURITY.md](./SECURITY.md).

## 🛠️Разработка и проверка сборки

Перед отправкой изменений запустите проверку:

```powershell
pwsh -File tests\Test-Build.ps1
```

Проверяются: стратегии и ссылки на файлы, конфиг, повторная проверка Auto-Select и пороги значимого выигрыша, privacy-фильтр и preview без изменения hosts/IPSet/логов, preview-планы DNS/network, все модульные части и их экспорт, манифест/CRC/UTF-8 релизного ZIP и отсутствие пользовательских данных. Те же проверки запускаются в CI (`.github/workflows/ci.yml`) и перед сборкой релиза (`.github/workflows/release.yml`).

Собрать чистую папку релиза и корректно именованный UTF-8 ZIP локально можно из Git-клона:

```powershell
pwsh -File tools\Build-Release.ps1 -OutputDirectory .\dist
```

Скрипт находится в исходном Git-клоне и не включается в пользовательский архив. Он создаёт рядом папку релиза, ZIP с UTF-8 именами и `SHA256SUMS.txt`, сверяет сумму ZIP перед завершением, не перезаписывает существующие результаты и исключает конфиг, логи, локальные списки, тесты и старые архивы. Модуль `src/Zapret.psm1` остаётся совместимым входом и экспортирует прежнюю поверхность функций; реализация разнесена по `src/parts/*.ps1`, все части входят в релиз. Workflow добавляет в тот же манифест SHA-256 для ZIP/RAR/TAR.GZ и проверяет их до публикации.

Чтобы добавить свою стратегию, достаточно дописать одну запись в `strategies.json` (аргументы winws без `%BIN%`/`%LISTS%` — используйте плейсхолдеры `{BIN} {LISTS} {GAME_TCP} {GAME_UDP}`), никакие .bat файлы создавать не нужно.
