- **Обновление в существующую папку** — `Update-Zapret.bat` запускает updater, который валидирует версию/состав ZIP и SHA-256 при наличии манифеста, сохраняет пользовательские настройки, предварительно проверяет блокировку `WinDivert64.sys`, транзакционно заменяет только файлы пакета и пытается откатить замену при ошибке. Драйверные службы и процессы учитываются только если они указывают на выбранную папку установки.
- **Приватный support-bundle с предварительным просмотром** — перед сбором `support-bundle -Preview` показывает состав, назначение и режим приватности. По умолчанию фильтруются имя/пути профиля, частные IP, MAC, e-mail и распространённые токены/пароли; пользовательские стратегии не включаются. `-IncludeSensitive` — явный opt-out от редактирования. Исходные логи не изменяются; `privacy-report.txt` описывает фильтрацию, а проверка архива перед отправкой всё равно рекомендуется.
- **Предпросмотр системных изменений** — `-Preview` добавлен для DNS/DoH/rollback/benchmark, IPSet режима/обновления, hosts-update, network optimize/revert и MTU. Планы показывают текущие/целевые значения, нужные права, снимок и способ отката; preview не применяет системные настройки и обходит запрос UAC. Для списков используются временные файлы, исходники и rollback-состояние не меняются.
- **Модуль разбит на обслуживаемые части** — `src/Zapret.psm1` остался совместимым точкой импорта; implementation части под `src/parts/` загружаются в фиксированном порядке в тот же scope, а `Export-ModuleMember -Function *` сохраняет прежнюю поверхность функций. Release builder явно включает все части.
- **SHA256SUMS.txt в релизе** — `Build-Release.ps1` создаёт и сверяет манифест ZIP; release workflow добавляет ZIP/RAR/TAR.GZ, автоматически выполняет `sha256sum --check` и прикладывает файл к GitHub Release.
- **Чистая сборка релиза** — `tools/Build-Release.ps1` формирует versioned-папку и ZIP с корректными UTF-8 именами только из отслеживаемых runtime-файлов и явного списка документов/entry points; исключает локальные конфиги, логи, пользовательские списки, тесты и старые архивы. Скрипт проверяет соответствие версии и UTF-8-флаг имени `ИНСТРУКЦИЯ.txt` внутри ZIP, поддерживает `-WhatIf` и не перезаписывает существующие результаты. Release workflow использует тот же сборщик.
- **Guided Auto-Setup (`zapret.ps1 auto-setup`, меню 25)** — единый мастер для обычного и мобильного интернета: спрашивает тип подключения, а для мобильного — оператора и затем запускает соответствующий профиль. Auto-Select только проверяет; установка и настройка hosts/IPSet требуют явного согласия (пустой ответ — отказ). `-Install` явно подтверждает применение обоих изменений. DNS и системные сетевые параметры мастер не меняет; еженедельная задача предлагается отдельно и также требует согласия.
- **Network & Ping Tools (меню 23)** — DNS benchmark пяти DoH-провайдеров (по 3 ICMP-пинга к IPv4 и 3 HTTPS-пробы DoH endpoint, среднее время ответа и предложение применить самого быстрого; при фильтрации ICMP используется HTTPS-тайминг); провайдеры Cloudflare, Google, Quad9, AdGuard и Yandex. Перед сменой DNS сохраняется `logs/rollback-dns-*.json`, восстановление — `zapret.ps1 dns rollback`; `dns reset` отдельно возвращает DHCP.
- **Сетевые твики с rollback** — `zapret.ps1 net-optimize` сохраняет `logs/rollback-net-<timestamp>.json`, выставляет `TcpAckFrequency=1`, `TCPNoDelay=1` для активных GUID интерфейсов, `NetworkThrottlingIndex=0xffffffff`, `SystemResponsiveness=10` и включает RSS через `netsh`; `net-optimize -Revert`/подменю восстанавливают последний сетевой снимок.
- **MTU и качество линии** — `mtu-check` бинарным поиском проверяет payload 1200–1472 байта через `ping.exe -n 1 -w 1000 -f -l`, выводит текущий и измеренный MTU, предлагает применить через `netsh` со снимком отката. `ping-test` делает 10 измерений до шлюза, `1.1.1.1` и `discord.com`; считает min/avg/max/jitter/loss и предупреждает о проблемах Wi-Fi/кабеля при деградации уже до шлюза.
- **Проверка зависания и скорости загрузки в Auto-Select** — `-CheckFreeze` скачивает диапазон `0-65535` (полные 65 536 байт) с двух HTTPS-целей; HTTP 200/206 засчитывается только при полном объёме, `-Deep` включает проверку автоматически. Сохраняется средняя скорость `SpeedKBs`; при равном числе пройденных целей стратегии быстрее 200 КБ/с ранжируются выше.
- **Временная пауза обхода** — `zapret.ps1 pause [Minutes]` и пункт меню 22 останавливают службу/процесс `winws.exe`, выгружают и удаляют регистрации только тех WinDivert/WinDivert14, чей путь ведёт в `bin` этой установки, затем возобновляют исходную службу или вручную запущенную стратегию. Таймер можно завершить клавишей; hosts, config.json и scheduled task не меняются.
- **Управление пользовательскими доменами** — `domain remove` удаляет точное имя из обоих списков; меню «Мои сайты» умеет открыть/сбросить списки и найти домены через DNS-кэш (`discover-domains`), отфильтровывая системные домены Windows.
- **Рекомендации сайтов в «Мои сайты»** — пункт `8` предлагает Telegram, YouTube, Discord, WhatsApp, Instagram, Facebook, TikTok, X и Twitch; перед изменением показывает домены и спрашивает подтверждение. Существующие исключения не обходятся, шаблонные `domain.example.abc` не учитываются в счётчиках, а одного host-списка может быть недостаточно для Telegram Desktop.
- **Обмен стратегиями** — чистые `ConvertTo-StrategyShareString` / `ConvertFrom-StrategyShareString` и команды `export-strategy` / `import-strategy` передают одну сжатую строку `zapret1:` (лимит 16 КБ); проверяются JSON-поля, ID и allow-list аргументов. Import/export также добавлены в меню Clone Strategy.
- **Диагностика и onboarding** — doctor сверяет часы с HTTPS `Date` за 3 секунды, проверяет активные глобальные IPv6-адреса и предупреждает о возможной блокировке WinDivert параметром HVCI при остановленном `winws.exe`; при первом открытии меню без config.json и службы предлагается Auto-Select `[Y/n]`.
- В баннере службы `RUNNING` отображается зелёным, `STOPPED` красным, `IPSet: any` жёлтым.

### Bug fixes
- **Повтор Auto-Select** — повторная проверка теперь получает определение стратегии по ID лидера, а не объект строки рейтинга; отчёт показывает причину неудачи/пропуска повтора и результаты отдельных целей.
- **Auto-Select fail-closed gate** — the top result is re-run before an install; endpoint and successful transfer sets must match. An installed strategy is not replaced for one-target noise: a candidate must add at least two reachable endpoints, add a service without losing total endpoint coverage, or deliver a repeat-verified ≥25% and ≥50 KB/s transfer-speed gain at equal coverage. An active strategy omitted from the candidate set is measured as a baseline; if it cannot be identified or measured, the gate stays closed. Declining installation resumes a previously running service, restarts a recognized manual strategy (otherwise it prints its restart command), and leaves a previously stopped service stopped. The benchmark now reads the optional target `Service` field safely and falls back to the endpoint name, so an older/partial target list cannot abort every strategy run. Guided Auto-Setup consumes the same confidence result, and carrier preferences are saved only after repeat verification.
- `Remove-ZapretServices` теперь использует проверку владения драйвером из pause-пути: `WinDivert`/`WinDivert14` останавливаются и удаляются только если `PathName` указывает на подходящий драйвер в `bin` этой установки; чужая служба остаётся нетронутой.
- CLI `zapret.ps1 uninstall` теперь явно проверяет маркер в системном файле hosts; `-RemoveHostsBlock` сам подтверждает удаление и не вызывает `Read-Host`. Без флага интерактивное удаление сохраняет вопрос с ответом по умолчанию «да».
- Исправлена ошибка Auto-Select при остановке ровно одного `winws.exe`: одиночный результат `Get-Process` теперь обрабатывается как массив и корректно считает элементы.

- В Auto-Select добавлен пошаговый вывод имени endpoint и HTTP-статуса; каждый сетевой probe ограничен `curl --max-time`, чтобы ожидание не выглядело как зависание.

Для WinDivert учитывается `bin` из `PathName` зарегистрированной службы `zapret`, в том числе путь старой папки после переноса; сторонние драйверы по-прежнему не удаляются.

## [2.1.1] - 2026-11-18

Аудит безопасности и исправление дефектов (по итогам ручного ревью и PSScriptAnalyzer).

### Security
- **Rollback не может выйти за пределы `logs\rollback-*`** — Restore-RollbackSnapshot проверяет, что папка снимка из config.json является прямым потомком logs с префиксом rollback- (Test-RollbackSnapshotPath). Подменённый config.json больше не может указать на чужую папку и перезаписать системный hosts/ipset.
- **Валидация загружаемого фрагмента hosts** (Test-HostsFragment): каждая строка должна быть пустой/комментарием/IPv4/IPv6 + hostname [+ trailing comment]; строгие октеты IPv4, лимит 512 КБ / 5000 строк; фрагмент только из комментариев отклоняется. Проверено на живом официальном списке (0 проблем).
- **Удаление управляемого блока hosts больше не удаляет хвост файла** при повреждённых маркерах: unbalanced begin/end marker → отказ с понятным сообщением (раньше всё после маркера удалялось). То же для пути замены блока (Get-UpdatedHostsContent).
- **Структурная валидация аргументов стратегии** в Expand-StrategyArgs: несбалансированные кавычки, batch-артефакты (%VAR%, ^), недостающий префикс `--wf-tcp=` — понятная ошибка вместо полусломанной командной строки winws (особенно для ручных strategies-user.json).
- **Имя сервиса для sc.exe берётся в кавычки** при остановке/отключении VPN-конфликтов (имена с пробелами).
- **Поиск curl.exe только среди приложений** (-CommandType Application): на PS 5.1 алиас curl→Invoke-WebRequest больше не может быть принят за curl.
- **dpi-checkers suite** (utils/test zapret.ps1): только TLS 1.2+; из удалённого JSON принимаются только хосты с валидным именем (`*.octets` / валидный hostname без path/userinfo/port) — произвольные URL-аргументы от скомпрометированного зеркала отбрасываются.
- **CLI hosts-update: произвольный -HostsPath разрешён только с -DryRun или для файла с именем `hosts`** — нельзя перезаписать чужой файл под админом.
- **Меню/лог rollback: управляющие символы вырезаются** из reason/strategy/time при чтении config.json (защита терминала от инъекции через подменённый config).
- **Время задачи автоперепроверки** принимается только в диапазоне 00:00–23:59.

### Bug fixes
- zapret.ps1: убраны обращения к автоматическим переменным ($Args→$StrategyArgs, $input→$rangeInput); мёртвые переменные в Show-Banner/Invoke-MenuGameFilter/utils; тесты используют $null слева в сравнениях; Test-Build.ps1 получил UTF-8 BOM.

- **Авто-ротация логов** — при каждом запуске: файлы старше 14 дней удаляются, в `logs\` хранится не более 20 файлов (rollback/backup-папки не трогаются).

## [2.0.1] - 2026-11-18

Доработка релиза под реальные проблемы поддержки и миграции (по итогам баг-репортов).

### Added
- **`support-bundle`** (CLI и пункт меню 17): собирает в один ZIP на Рабочем столе полный набор для баг-репорта по шаблону issue — вывод диагностики (в новом **read-only** режиме, ничего не меняет в системе), `dns status`, статус службы/WinDivert/winws/IPSet/Game Filter, `config.json`, последний `logs\auto-select-*.txt`, свежий `logs\zapret-*.log`, `system.txt` и `README.txt` с инструкцией, как прикрепить архив к GitHub issue.
- **Проверка пути запуска**: при старте `zapret.ps1` путь проверяется на кириллицу, пробелы, спецсимволы и `OneDrive`. Если найдено — предупреждение и предложение автоматически перенести папку в `C:\zapret` (robocopy /E /MOVE) с перезапуском оттуда. Главная причина падений winws.exe у новичков.
- **`auto-select -Fast`** (CLI): сначала проверяются текущая стратегия и топ-3 (`general`, `alt`, `fake-tls-auto`); если одна из них проходит 100% целей — перебор останавливается и она предлагается к установке (15 секунд вместо 5 минут в удачном случае). Иначе — обычный полный бенчмарк.
- **Проверка доступности DoH-провайдера** в `dns doh`: перед настройкой Cloudflare выполняется пробный HTTPS-запрос к `cloudflare-dns.com` (любой HTTP-ответ = провайдер доступен). Если endpoint заблокирован — предлагается переключение на `google` (8.8.8.8) или `quad9` (9.9.9.9); если не отвечает ни один — понятное сообщение про браузерный DoH и остановка.
- **`import-config <путь>`** (CLI и пункт меню 18): миграция настроек при обновлении — переносит `config.json`, `lists\*-user.txt`, `lists\ipset-all.txt` и `bin\ACTIVE_*.bin` из старой папки zapret в текущую (перезаписываемые файлы бэкапятся в `logs\import-backup-*`), затем переустанавливает службу с той же стратегией, что стояла раньше (имя стратегии читается из реестра `HKLM:\...\zapret`).
- **`Invoke-Diagnostics -ReadOnly`**: режим диагностики без каких-либо изменений (без удаления конфликтующих служб и очистки кэша Discord) — используется support-bundle.

### Tests
- `tests/Test-Build.ps1` расширен: валидация пути запуска, порядок и ранний выход `-Fast`, проба DoH-кодов, упаковка `support-bundle` (ZIP на временной папке, проверка содержимого), миграция `import-config` (копирование, бэкап, отклонение самосовпадения и чужой папки). Всего 173 проверки.

## [2.0.0] - 2026-11-18

Полный реворк архитектуры управления zapret. Исполняемые файлы (`bin\`), списки и фейки 1.x не менялись — обновление безопасно делать `Remove Services` → распаковка новой версии → `Install Service`.

### Added
- **`zapret.bat`** — новая единая точка входа: запрос прав администратора и запуск меню/CLI.
- **`zapret.ps1`** — движок на PowerShell: интерактивное меню **и полноценный CLI** (`list`, `run`, `install`, `uninstall`, `status`, `ipset`, `ipset-update`, `hosts-update`, `check-updates`, `game-filter`, `fakes`, `diagnostics`, `test`, `version`). Поведение и пункты меню 1.x сохранены.
- **`strategies.json`** — все 22 стратегии (`general`, `alt`…`alt13`, `exp`, `fake-tls-auto*`, `simple-fake*`) описаны данными с описанием на русском языке; аргументы шаблонизируются плейсхолдерами `{BIN} {LISTS} {GAME_TCP} {GAME_UDP}`. Добавить стратегию теперь можно без написания .bat файла.
- **`src\Zapret.psm1`** — общий модуль: конфигурация, движок стратегий, службы, ipset, hosts, диагностика. Код переиспользуется меню, CLI и тестами (раньше логика была скопирована между .bat и .ps1).
- **`config.json`** — единый файл настроек (игровой фильтр, авто-проверка обновлений). При первом запуске автоматически мигрирует из `utils\game_filter.enabled` и `utils\check_updates.enabled`.
- **`logs\zapret-*.log`** — журналирование установки службы, переключения ipset/игры, обновлений hosts/ipset и ошибок.
- **`tests\Test-Build.ps1`** — проверка сборки: валидность и уникальность стратегий, существование всех файлов из `bin\`/`lists\`, на которые ссылаются аргументы, валидация диапазонов портов, парсер ipset, сравнение версий, round-trip конфиг, синтаксис всех скриптов.
- **CI** (`.github/workflows/ci.yml`) — прогон проверки на `windows-latest` (pwsh 7 и Windows PowerShell 5.1) и `ubuntu-latest`.
- **`CHANGELOG.md`** — этот файл.
- **Auto-Select Best Strategy** — автоматический подбор стратегии именно для вашего ПК и вашего провайдера (`zapret.ps1 auto-select` или пункт меню `13`). Поочерёдно запускает каждую из 22 стратегий, проверяет, открываются ли Discord (main/gateway/CDN/updates) и YouTube, ранжирует по числу открытых целей и времени ответа, показывает таблицу, сохраняет отчёт в `logs/auto-select-*.txt` и по желанию ставит победителя как службу автозапуска. Флаги: `-Install` (без вопросов), `-Deep` (проверка HTTP/TLS1.2/TLS1.3 на цель, медленнее и точнее). Работающий обход при этом останавливается на время теста и восстанавливается в конце (побеждённая стратегия или предыдущая служба). После установки победителя инструмент предлагает сразу же обновить блок в `hosts` и свежий `ipset-all.txt`.
- **`zapret.ps1 dns status | dns doh <cloudflare|google|quad9> | dns reset`** — лечение DNS-poisoning одной командой: показывает DNS по каждому адаптеру, регистрирует шаблон DoH (Windows 11) и прописывает DNS провайдера с проверкой записью обратно; откат — `dns reset` (автоматический DHCP). То же самое в меню → `15. DNS / Secure DNS (DoH)`.
- **`zapret.ps1 uninstall [-RemoveHostsBlock]`** — полное удаление теперь включает еженедельную задачу `Zapret-AutoSelect` и (при интерактивном подтверждении, по умолчанию да) управляемый блок в `hosts` с резервной копией. `-RemoveHostsBlock` — то же самое без вопросов.
- **`zapret.ps1 help`** — печатает встроенную справку напрямую (раньше на некоторых хостах выводился только синтаксис параметров).
- **Резервные копии hosts/ipset** теперь включают миллисекунды в имени (защита от перезаписи бэкапа в пределах одной секунды).
- **`tests/Test-Build.ps1`** — добавлены проверки снятия управляемого блока hosts (dry-run/удаление/идемпотентность), интеграционный smoke-прогон CLI на временной копии репозитория (`list`, `version`, `game-filter`, `status`, неизвестное действие) и раздел `== Security checks ==`. Всего 125 проверок.
### Security (аудит)
- **Release workflow (`release.yml`)**: `${{ github.event.inputs.tag }}` больше не подставляется напрямую в `run:` блоки — тег проходит через `env: TAG` и валидируется регулярным выражением `X.Y.Z` до любого использования. Удалён класс инъекции через вход workflow_dispatch.
- **`release.yml` теперь включает `.service/` в архив** — раньше релиз собирался без `version.txt`, и каждый клиент показывал `v0.0.0` + ложное «доступно обновление» на каждом запуске.
- **`zapret.bat`** больше не пересобирает командную строку через `-Command "Start-Process ..."` (туда попадали аргументы пользователя) — elevate выполняет сам `zapret.ps1` с валидированными и экранированными аргументами; `zapret.bat` просто вызывает `-File`.
- **`zapret.ps1 fakes`** — имя фейка валидируется (`^[A-Za-z0-9][A-Za-z0-9_.-]{0,63}$`), traversal-пути отклоняются до обращения к файловой системе.
- **`Enable-Doh`** — адаптеры с небезопасными именами (`"`/backtick) пропускаются с предупреждением (безопасность netsh-парсинга).
- **`Install-ZapretService` / `Set-AutoSelectSchedule`** — сборка PathName/schtasks payload через чистые функции `Get-WinwsPathName` / `Get-AutoSelectTaskArguments`, которые отклоняют пути с `"`.
- **Диагностика** — новая проверка Authenticode-подписей бинарников в `bin\` (winws.exe, WinDivert.dll/.sys, cygwin1.dll): `HashMismatch` = FAIL (файл изменён после подписания — подмена), отсутствующая подпись = WARN, всё валидно = OK. Не-Windows → пропуск.
- **`SECURITY.md`** — как проверить, что вы запускаете; **`.github/dependabot.yml`** — автообновления GitHub Actions.
- **`Set-IpsetMode`** — все переходы режимов теперь без потери данных: `any` делает резервную копию списка перед очисткой, `loaded` сохраняет бэкап (раньше циклическое переключение ломало «недоступен backup» и могло уничтожить скачанный список).
- **Статический скан в тестах**: отсутствие `Invoke-Expression`/`iex`/`cmd.exe /c`/`& cmd` в поставляемых источниках, наличие `Assert-Admin` в привилегированных функциях, отсутствие `${{ }}`-инъекций в `run:` блоков workflows, проверка точки входа bat-файлов. Раздел `== Security checks ==` в `tests/Test-Build.ps1` (125 проверок суммарно).

- **`zapret.ps1 schedule-autoselect enable|disable|status`** — еженедельная задача Windows (вс, 03:30, под SYSTEM), которая заново прогоняет все стратегии и переустанавливает лучшую. Стратегии со временем перестают работать (провайдеры адаптируются) — так обход починит себя сам. В меню → `16. Weekly Auto Re-Check`.

### Changed
- **`service.bat`** — устарел, теперь это тонкий алиас на `zapret.bat` (старый синтаксис и привычки продолжают работать).
- **Выбор стратегии для установки службы** — по списку с описаниями из `strategies.json`; установка не парсит .bat файлы регулярными выражениями (как раньше), а использует готовый шаблон аргументов.
- **Служба `zapret`** создаётся через `Win32_Service` (с откатом на `sc.exe`), регистрирует имя стратегии в `HKLM\...\Services\zapret`.
- **`Update Hosts File`** — больше не требует ручного копирования из блокнота: записи ставятся маркированным блоком `# >>> zapret-discord-youtube (managed) >>>` в конец `hosts`, при обновлениях блок заменяется целиком, перед изменением создаётся резервная копия `hosts.zapret-bak-<дата>`, при недоступности — печатаются ручные инструкции.
- **`Update IPSet List`** — скачивание в temp-файл с проверкой содержимого (не меньше 100 записей CIDR, без посторонних строк) и откатом на старую версию при любой ошибке; старая версия сохраняется в `ipset-all.txt.bak`.
- **Проверка обновлений** — сравнение семантических версий (а не строковое равенство), `curl` с откатом на `Invoke-WebRequest`, таймауты и защита от повреждённого ответа.
- **Диагностика** — структурирована: общий итог «N passed, M warnings, K problems»; штандартные проверки не зависят от языка системы больше, чем раньше (английские маркеры netsh/sc, допущение к ошибкам реестра); все Windows-специфичные проверки корректно пропускаются не на Windows.
- **`utils\test zapret.ps1`** — вместо запуска `general*.bat` запускает `winws.exe` напрямую с развёрнутыми из `strategies.json` аргументами; логика измерений, DPI-чекеры и отчёт сохранены без изменений.
- **`.gitignore`** — добавлены `logs\`, `config.json`, резервные копии ipset; **`.gitattributes`** — добавлены `*.psm1`, `*.json`.
- **Диагностика** — новый пункт: предупреждение, если включён Game Filter (winws перехватывает игровой трафик — для минимального пинга держите его выключенным).
- **`release.yml`** — перед упаковкой релиза запускается `tests/Test-Build.ps1`; в архив входят `zapret.bat`, `zapret.ps1`, `service.bat`, `strategies.json`, `src\`, `utils\`, `bin\`, `lists\`, `README.md`, `LICENSE.txt`, `CHANGELOG.md`.

### Removed
- **Все 22 файла `general*.bat`** — стратегии переехали в `strategies.json`; запуск через `zapret.bat` → меню, `zapret.ps1 run <id>` или `Install Service`.

### Fixed
- Возможная ошибка при запуске на системах без переменной `TEMP`/`SystemRoot` (fallback на пути по умолчанию).
- Миграция `game_filter.enabled`: пустой параметр `tcp`/`udp` больше не сбрасывает режим; корректна обработка `all`.
- Меню больше не зацикливается при закрытии stdin (non-interactive запуск) — трактуется как «назад/выход».
- Снято предупреждение PowerShell об unapproved verbs при импорте модуля.
- `FAKE TLS AUTO` стратегия: `--dpi-desync-fake-tls=!` теперь передаётся winws как `!` (бат-экранирование `^!` корректно сконвертировано при извлечении).

### Compatibility
- Windows 10/11, Windows PowerShell 5.1+ (и PowerShell 7+).
- Пользовательские данные (`list-*-user.txt`, `ipset-exclude-user.txt`, `ipset-all.txt`) и фейки (`ACTIVE_*.bin`) полностью совместимы с 1.x.
